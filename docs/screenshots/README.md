# Screenshots

Capture these from the running app using the demo data (`python manage.py seed_demo`), then save them in this folder
with these exact names so the root README picks them up.

| File | What to capture |
| --- | --- |
| `home.png` | Customer home with the balance visible, limits, and recent activity |
| `home-hidden.png` | The same screen with the balance hidden (eye icon) |
| `send-money.png` | Send money at the SMS-code step, with the code field showing |
| `ledger.png` | The full ledger with Out and In columns |
| `teller-desk.png` | Teller desk with an account looked up and a deposit under review |
| `admin-ledger.png` | Django admin ledger entries, to show the double entries |
| `tests.png` | Terminal showing the test run passing, and `Reconciliation OK` |

Tips: use a browser window around 1200 px wide, capture a mobile-width one of the home screen too, and avoid
anything that isn't demo data.
